# Lab-5-Sunflower
This project is a digital sunflower inspired by how plants respond to sunlight. Using a webcam and a Teachable Machine model, the website detects light and dark objects.

When light is detected, the sunflower grows and opens. When darkness is detected, it closes.

Link to model url: https://teachablemachine.withgoogle.com/models/RgNspmd3u/
